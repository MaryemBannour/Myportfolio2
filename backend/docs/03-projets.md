## CineScope
**2023 — 2ᵉ année Licence**

Plateforme web de découverte de films et séries avec un système de recommandations personnalisées, un catalogue de nouveautés et classiques, et un système de notation.

Technologies : React.js, TMDB API, Tailwind CSS.

CineScope est mon tout premier projet développé. Même si c'est un projet simple, il m'a énormément appris sur le développement web dans son ensemble et a posé les bases de tout ce que j'ai construit depuis.

## Chatbot RAG (ce projet même !)
**2026**

Chatbot conversationnel intégré à mon portfolio, capable de répondre aux questions des visiteurs sur mon parcours, mes projets et mes compétences. Architecture RAG (Retrieval-Augmented Generation) : les documents sur mon profil sont découpés en chunks, transformés en embeddings via l'API Gemini, stockés dans une base vectorielle Chroma, puis recherchés par similarité pour construire le contexte injecté dans le prompt envoyé au modèle Gemini Flash.

Technologies : Node.js, Express, React, Chroma, Google Gemini API.
